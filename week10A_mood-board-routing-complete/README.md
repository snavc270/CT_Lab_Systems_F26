# Mood Board, multi-page edition: everything solved (Week 10A)

Reference version of the Week 10A activity with the optional and extra-practice parts finished. Look for `OPTIONAL` and `STRETCH` comments in the code.

## Run it

```bash
npm install
npm run dev
```

## Extras on top of the lesson's final code

- **Drag to rearrange** (optional section): `moveImage` in `App.jsx`, drag state in `Board.jsx`, drag events and styles in `ImageCard.jsx` / `ImageCard.css`
- **Clickable tags on each card** ("Your turn" in Step 4): `onTagClick` in `ImageCard.jsx`
- **Previous / next links** on the detail page, following the board's current order: `ImageDetail.jsx`
- **A `/liked` page**: `pages/Liked.jsx`
- **`NavLink`** for highlighting the current page: `App.jsx` and `nav a.active` in `App.css`

Note: the browser's built-in drag and drop doesn't work on phones and tablets.
